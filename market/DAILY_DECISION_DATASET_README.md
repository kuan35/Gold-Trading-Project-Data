# 每日「今天會不會交易」資料集說明

`decision_point_dataset_*` 只有他真的下單的紀錄（全部是正樣本），這份補上「那天
他完全沒交易」的負樣本，兩者標記在同一個資料集裡，讓「今天該不該進場」這個
二元分類問題有負樣本可以訓練。

## 標籤定義

`label_traded`：那個 UTC 交易日，有沒有至少一筆已確認時區券商的 XAU/USD 交易
（1＝有交易，0＝完全沒交易）。**這是日級別的標籤，不是分鐘級別**——因為特徵目前
只有日線解析度，沒有「這一分鐘算不算沒進場」的資料基礎，日級別跟特徵精細度一致。

## 類別分布

- 總天數：1553
- 有交易的天數：210
- 沒交易的天數：1343
- 比例約 1：6.4，不算極端不平衡

## 四個檔案，兩種處理不平衡的方式，挑一種用即可

- `daily_decision_dataset_v1/v2_*.csv`：**全部 1553 天**，多一欄
  `sample_weight`——訓練時把這欄位傳進 `model.fit(..., sample_weight=...)`，
  不用自己設定 `class_weight='balanced'`，任何模型/套件都適用。權重公式是
  sklearn `class_weight='balanced'` 的標準算法：`總數/(2×該類別數量)`。
- `daily_decision_dataset_balanced_v1/v2_*.csv`：**已經處理成 1:1 平衡**的子集
  （全部正樣本 + 固定亂數種子抽出的等量負樣本，共 420 天），
  不想處理權重的話直接用這份，但注意這份只用了部分負樣本，資訊量比全量版少。

**兩種只需要選一種，不要同時用**（例如已經用平衡版就不要又加sample_weight，會重複處理）。

## 限制

- 這是日級別標籤，不是分鐘級別，沒辦法回答「這一天裡哪個時間點該不該進場」，
  只能回答「今天整體看起來值不值得交易」
- 沒交易的那 1343 天，不代表他當時「看過但決定不做」——也可能
  是他根本沒開盤查看，這份資料沒辦法區分這兩種情況，只能記錄結果不記錄原因
- 平衡子集用隨機抽樣（固定種子 20260914，可重現），但抽到的負樣本天不必然是
  「最接近他會交易的臨界情況」的那種，資訊量比不上真正的 near-miss 負樣本
