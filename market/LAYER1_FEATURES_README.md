# Layer 1 特徵資料說明

給 ML 版本兩組比較用的資料，來源都是 `xauusd_daily_bars.csv`（Dukascopy 日線，
抓取範圍 2020-01-01 到 2025-12-30，共 1865 筆；
輸出檔案只保留 2021-01-03 到 2025-12-30，共 1553 筆——前面那段是算均線/指標用的歷史緩衝，本身不是訓練資料，故不輸出。

## 兩個檔案

- `layer1_features_v1_no_indicators.csv`：貼近交易員訪談（Q9）實際會看的特徵
- `layer1_features_v2_with_indicators.csv`：v1 全部欄位 + RSI/MACD/布林通道/ATR

**兩份檔案前面欄位完全一樣，只有 v2 多了技術指標那幾欄**，訓練切分（train/valid
時間範圍）務必兩版本使用同一組，只讓「加不加技術指標」這一個變因不同。

## 欄位說明

| 欄位 | 意義 | 備註 |
|---|---|---|
| sma_120 / sma_240 | 120/240日簡單移動平均 | 前119/239筆為空，point-in-time |
| above_sma_120 / above_sma_240 | 收盤是否站上該均線 | |
| trend_label | 偏多／偏空／盤整 | 兩條均線都站上=偏多，都跌破=偏空，其餘=盤整 |
| volume_backed_candle | 是否為帶量K棒 | 量>前20筆均量×1.5 且收陽 |
| resistance / support | 近50筆高低點 | |
| distance_to_resistance_pct / distance_to_support_pct | 距離壓力/支撐的百分比 | |
| trendline_slope / trendline_r_squared / trendline_price_above | 斜率線代理特徵 | 近20筆線性回歸擬合，**只是近似值，不是複製交易員的真實判斷**，見下方限制 |
| rsi_14 / macd_* / bb_* / atr_14 | 標準技術指標 | 只在 v2，交易員訪談明講不看這些（Q9），純粹為了老師要求的比較測試 |

## 目前沒有包含、之後要補的

- **交易時段**（09:30／18:00／00:00 台灣時間前後一小時）：這批資料只有日線，
  沒有意義的「一天中的時間」可以判斷，需要先抓 1H／15-30分／1-5分的資料才能加
- **距重大數據分鐘數**：還沒接經濟數據行事曆來源，之後補
- **帳戶狀態**（累計手數／加碼次數／浮動損益）：這是交易員自己的對帳單資料，
  不是市場資料，在 `artifacts/data_quality/parsed_records.csv`，要在決策時間點
  層級另外 join 進來，不屬於這份市場資料匯出

## 資料限制

- Dukascopy 是 UTC，跟對帳單的券商伺服器時間尚未逐日交叉核對過
- 只有日線，短週期特徵（1H/15-30分/1-5分）還沒做
- 斜率線是近似代理特徵，不是真正複製交易員的手繪判斷
